# 천사데이 D-day 영상

제14회 천사데이 찬스바자회(2026년 10월 17일 토요일, 홀리씨즈교회) 홍보 영상을 D-day 숫자별로 받는 페이지입니다.

- 페이지: https://yyc9920.github.io/cheonsaday-dday/
- 영상 파일: [Releases › videos-v1](https://github.com/yyc9920/cheonsaday-dday/releases/tag/videos-v1) — `dday-<숫자>-<story|poster>.mp4` (숫자 0 = D-DAY)

`motion.html`이 영상의 원본 애니메이션입니다. `motion.html?v=1&ratio=story&d=7`처럼 열면 그 D-day로 재생됩니다.
영상은 이 애니메이션을 프레임 단위로 캡처해 만들었습니다(Playwright + ffmpeg, 1080×1920 / 1080×1512, 30fps, 18초).
